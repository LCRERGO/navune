# ADR 0019 — Java and Rust tree-sitter adapters

- Status: accepted
- Date: 2026-09-17
- Decision-maker: product owner via design interview

## Context

ADR 0002 staged the languages; ADR 0017 established the template for a
tree-sitter language pair (a shared adapter package, explicit extension
mapping, internal-only edges, a self-contained fixture, and evolution-suite
coverage). The official Go bindings for `tree-sitter-java` and
`tree-sitter-rust` are available and already resolvable; both require cgo.

The two languages differ from the existing ones in ways that force explicit
decisions:

- **Java** has no `go.mod`-style source root. Imports are fully-qualified type
  names (`com.example.Foo`, `com.example.*`) resolved against declared
  `package` clauses.
- **Rust** uses a file-path module system (`mod foo;`, `use crate::a::b`), and
  its tests are frequently inline `#[cfg(test)] mod tests { … }` inside a
  production file.

## Decision

Add two adapters, `internal/lang/java` and `internal/lang/rust`, implementing
`lang.Parser` over the `tree-sitter-java` and `tree-sitter-rust` grammars. Both
implement the full ADR 0015 measure set (size, cyclomatic and cognitive
complexity, comments, function shape, duplication tokens, calls) and the ADR
0016 smell layer, exactly as the existing adapters do.

**Extensions and tests.** `.java` and `.rs`. Java test files are `*Test.java`,
`*Tests.java`, `*TestCase.java`, or `Test*.java`; Rust test files are
`test_*.rs`/`*_test.rs`. Both also honour the directory rule (`test`/`tests`
path component). Inline Rust `#[cfg(test)]` code is **not** separated — the
file-level unit of analysis (ADR 0006) cannot split it, so it counts as
production; this is a documented limitation.

**Type layer and abstractness.**
- Java types: `class`, `interface`, `enum`, `record`, `@interface`; abstract =
  `interface`, `@interface`, and classes with the `abstract` modifier.
- Rust types: `struct`, `enum`, `trait`, `union`; abstract = `trait`.

**Cyclomatic complexity.** Java: base 1, +1 per `if`, `for`, enhanced `for`,
`while`, `do`, `catch`, ternary, each non-`default` `case`, and each `&&`/`||`.
Rust: base 1, +1 per `if` (including `if let`), each `match` arm beyond the
first, `while`/`while let`, `loop`, `for`, each `?`, and each `&&`/`||`.

**Cognitive complexity.** The existing depth-tracking model is extended: Java
`switch`/`catch`/ternary add `1+depth`; Rust `match` adds `1+depth` with arm
bodies evaluated one level deeper, `if let`/`while let` behave as `if`/`while`,
and `?` adds 1 with no depth. Java lambdas/anonymous-class bodies and Rust
closures are separate function units (`<anonymous@Lstart>`), resetting depth.

**Import resolution (internal-only, ADR 0010).**
- Java: a package index built from the analyzed files' declared packages;
  `import a.b.C` maps to the file declaring `a.b.C`, and `import a.b.*` maps to
  every analyzed file in package `a.b`. Everything else is external.
- Rust: `mod foo;` resolves to `foo.rs`/`foo/mod.rs` beside the file; `crate::`
  paths resolve under `src/` (falling back to the analysis root), `self::`
  beside the file, and `super::` one module directory up. External crates never
  become edges.

**Generated code.** Comment markers `Code generated … DO NOT EDIT.`,
`@generated`, and `<auto-generated>`, plus Java's `@Generated` annotation.

**Excludes.** `target` (Maven/Cargo), `.gradle`, and `out` join the built-in
directory excludes.

**Fixtures and verification.** `test/fixture-java` and `test/fixture-rust` are
self-contained modules (a nested `go.mod` keeps them out of Go tooling and
self-analysis) with an import/module cycle, a test file, a generated file, and
an excluded build directory. Integration tests live beside the existing
multilanguage tests; the evolution suite gains Java and Rust step generators
for complexity, cycles, duplication, and smells.

`navune version` lists `java` and `rust`, and `lang.Languages()` includes them
so per-language smell defaults and budget keys work automatically.

## Consequences

- The whole tool still requires cgo; two more grammars are compiled in.
- Rust inline tests are counted as production code — a known, documented gap.
- Java resolution depends on declared `package` clauses; files without one
  contribute no package index entries.
- The adapters are structurally close to the existing tree-sitter adapters,
  which raises Navune's self-measured duplication (a warn-tier signal only).
